丸サ進行

IVmaj7 → III7 → VIm7 → Vm7(→I7)
おしゃれでシティポップ的な響き。最後のVm7は本来I7につなぐことが多い。

弾きやすいキー

キーC（Fmaj7 → E7 → Am7 → Cm7）、キーG（Cmaj7 → B7 → Em7 → Gm7）、キーD（Gmaj7 → F#7 → Bm7 → Dm7）

よくある質問

丸サ進行とは？

IVmaj7 → III7 → VIm7 → Vm7(→I7)と進むコード進行。おしゃれでシティポップ的な響き。最後のVm7は本来I7につなぐことが多い。

丸サ進行を一番簡単に弾けるキーは？

ローコードだけで弾きやすいのはCです。
