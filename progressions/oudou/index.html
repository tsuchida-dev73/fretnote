王道進行

IVmaj7 → V7 → IIIm7 → VIm
J-POPで最も多く使われる進行のひとつ。切なさと高揚感が同居し、サビの定番。

弾きやすいキー

キーC（Fmaj7 → G7 → Em7 → Am）、キーF（Bbmaj7 → C7 → Am7 → Dm）、キーG（Cmaj7 → D7 → Bm7 → Em）

よくある質問

王道進行とは？

IVmaj7 → V7 → IIIm7 → VImと進むコード進行。J-POPで最も多く使われる進行のひとつ。切なさと高揚感が同居し、サビの定番。

王道進行を一番簡単に弾けるキーは？

ローコードだけで弾きやすいのはCです。
