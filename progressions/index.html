定番コード進行

J-POPやバラードでよく使われるコード進行を、全12キーのコード表と押さえ方つきでまとめています。

  • 王道進行IVmaj7 → V7 → IIIm7 → VImJ-POPで最も多く使われる進行のひとつ。切なさと高揚感が同居し、サビの定番。
  • カノン進行I → V → VIm → IIIm → IV → I → IV → Vパッヘルベルのカノン由来。ベースが順に下がっていく安心感があり、卒業ソングやバラードで多用される。
  • 小室進行VIm → IV → V → Iマイナーから始まる疾走感のある進行。90年代のヒット曲で多用され、今も定番。
  • 丸サ進行IVmaj7 → III7 → VIm7 → Vm7(→I7)おしゃれでシティポップ的な響き。最後のVm7は本来I7につなぐことが多い。
  • 1-6-4-5進行（50年代進行）I → VIm → IV → Vオールディーズの定番。初心者でもローコードだけで弾きやすい。
  • 1-5-6-4進行I → V → VIm → IV洋楽ポップスで非常に多い進行。ループさせるだけで曲の雰囲気が出る。
